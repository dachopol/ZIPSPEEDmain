# Competitive UI/Product Benchmark — 2026-09-23

This document records product principles only; it is not a ranking and does not copy competitor UI/assets.

## Speedtest by Ookla
Current Play listing emphasizes one-tap testing, real-time connection-consistency graphs, detailed past tests and sharing. Its current update notes also mention making the testing experience easier to read.

**Zipspeed response:** retain one GO/STOP action, live trace, history/share and improve visual reading order.

## Opensignal
Current Play listing emphasizes download, upload and latency plus broader mobile/network context.

**Zipspeed response:** keep core measured metrics together and keep network context on a separate Status view so the primary speed flow stays focused.

## FAST Speed Test
Current Play listing emphasizes a streamlined design that is fast and easy to understand.

**Zipspeed response:** preserve low-friction primary testing and avoid feature clutter in the main instrument.

## Meteor
Current Play listing emphasizes download/upload/latency plus how connectivity affects real-world app use.

**Zipspeed response:** retain the evidence-labeled streaming suitability view derived from the latest measured download; do not present it as a playback test.

## Zipspeed differentiation
- Premium dimensional instrument presentation.
- Explicit Real Data / Anti-Random rules.
- Unknown data stays unknown.
- No invented map/server position.
- No simulated ads/billing/server status.
- Layout depth must not create control or text overlap.

## Current gaps
- No authorized worldwide server directory.
- No real playback-quality test.
- No verified coverage map dataset.
- Runtime visual validation on real devices remains required.
