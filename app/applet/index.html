Research & Methodology Specification

Zipspeed was built with an uncompromising commitment to truth in network telemetry. Many popular speed tests inject artificial curves, synthetic jitter, or advertise peak burst TCP rates instead of actual sustained HTTP payload throughput.

1. Sustained HTTP Throughput:
Formula: (Total Bytes Transferred × 8) / (Elapsed Time in ms × 1000).
Calculated strictly on confirmed HTTP 200 responses with actual byte counts.
2. HTTP Latency Jitter Indicator:
Calculated as the mean absolute difference between consecutive successful HTTP-latency samples: ∑|L(i) - L(i-1)| / (N - 1). It is not labelled as ICMP jitter.
3. HTTP Probe Failure Rate ≠ Packet Loss:
HTTP probe failures reflect application/TCP level timeouts and handshake errors, which are fundamentally distinct from ICMP layer-3 packet loss. We label this truthfully as HTTP Probe Fail %.
4. Deterministic Gauge Scale:
The gauge needle uses a pure logarithmic interpolation from 145° (0 Mbps) to 395° (1000 Mbps). No random needle oscillations are permitted.
5. Strict Persistence Invariant:
Aborted, incomplete, or corrupted test sessions are never saved to history. Only fully verified test runs qualify.
