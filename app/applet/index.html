Privacy & Data

What this build actually does

These facts are derived from the current app source and must change if the implementation changes.

Measurement traffic

Speed tests contact the listed measurement provider directly. Your IP/network metadata can be visible to that provider and may be shown in Status.

Local history

Completed test history is stored locally on this device. Client IP and ISP metadata are not written into Zipspeed history.

Device permissions

This Android build requests internet/network-state access and does not request camera, microphone or device location permissions.

Ads & billing

No advertising or billing SDK is present in this build. Store declarations must be updated before either is added.

Browser network hint

When available, browser connection estimates are displayed locally. Zipspeed does not save these hints in History or send them to a new destination.

Optional M-Lab discovery

Only when you tap Discover, Zipspeed contacts the M-Lab Locate API to list NDT7 servers. If you enter a country code, that code is sent as a Locate query parameter. This build does not run an M-Lab measurement.

Measurement truth

Throughput uses actual transferred bytes and elapsed time. Failed or incomplete tests are not saved.
